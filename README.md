## 📌 About The Game / عن اللعبة
لعبة ثلاثية الأبعاد تفاعلية يقفز فيها الأرنب على منصات ملونة بناءً على بطاقات لونية وعداد تنازلي قبل سقوط المنصات!  
An interactive 3D platformer where a bunny hops across colorful blocks based on color cards and a countdown timer before platforms collapse!

---

## 🚀 Key Features / المميزات الرئيسية
- 🎲 **Randomized Colors:** خوارزمية لتغيير ترتيب الألوان عشوائياً في كل جولة.  
  Smart color-shuffling algorithm for dynamic rounds.
- ⏱️ **Timer System:** عداد تنازلي دقيق (5 ثوانٍ لكل لون) لزيادة الحماس.  
  Precise 5-second round timer for continuous challenge.
- 🎮 **Decoupled UI:** واجهات تفاعلية سلسة لشاشات البدء والنهاية والنتيجة.  
  Clean, decoupled UI system for start, end, and stats screens.

---
